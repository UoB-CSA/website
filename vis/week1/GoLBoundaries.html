How Modular Arithmetic Works

In C, wrapping around an array of size WIDTH is handled by the modulo operator %.

Equation:
nx = (x + dx + WIDTH) % WIDTH;

  • Blue (Target): The current cell (x, y)
  • Yellow: Standard neighbors.
  • Orange: Neighbors wrapping across the boundary.
