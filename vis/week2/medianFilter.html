How Reconstruction Works:

Instead of appending chunks in random order as they finish, the main thread runs a strict loop: for i := 0; i < threads; i++. It blocks on part := <-out[i].

Even if Thread 3 finishes first, the main thread will wait until Thread 0 finishes and pushes to out[0]. Once out[0] is read, it appends Slice 0 to newPixelData, then moves to listen to out[1]. This guarantees the final 2D slice is reconstructed in perfectly sequential top-to-bottom order.
